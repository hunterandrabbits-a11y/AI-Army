# AI数班

汽车行业数字员工管理后台 —— 高保真原型 + 产品文档。

## 目录结构

```
0826/
├── app/                  可运行交付物（HTML 与 assets 必须同目录，整体移动）
│   ├── AI数班-AI军团原型.html         主应用，单页 ~25k 行
│   ├── AI数班-V1.4-直播场控专家-原型.html
│   ├── 数班-用户服务协议.md            登录页 href 引用，勿单独移动
│   ├── 数班-隐私政策.md
│   └── assets/                        运行时资源（JS/CSS 模块、人物图、车型图等）
│
├── docs/
│   ├── prd/                          PRD-v1.0 / v1.2 / v3.0 / v1.3 / v1.4
│   ├── reviews/                      评审与会议记录
│   └── reference/                    独立参考页（对话消息类型、数字人模块地图）
│
├── design-system/                    设计令牌与分页面规范
│   ├── MASTER.md                     规范主文件
│   └── pages/                        dashboard / plaza / results / live
│
├── archive/demos/                    被取代的历史 demo 快照
└── AGENTS.md                         给 AI 编码工具的仓库说明
```

## 跑起来

```bash
cd app && python3 -m http.server 4175
# 打开 http://127.0.0.1:4175/AI数班-AI军团原型.html#dashboard
```

主 HTML 通过相对路径引用 `assets/`，**两者必须同目录**。移动时请把 `app/` 整个目录一起移动，不要只挪 HTML。

## 文档命名约定

**PRD** —— `PRD-v{版本}-{模块}.md`。版本号以文档内 `> 版本：` 字段为准：

| 文件 | 模块 |
|---|---|
| PRD-v1.0.md | 全局业务逻辑（只读，改动前先确认） |
| PRD-v1.2-成果中心重构.md | 成果中心 |
| PRD-v3.0-对话逻辑设计方案.md | 对话与小班 |
| PRD-v1.3-短视频运营专员.md | 短视频运营专员（当前主线） |
| PRD-v1.4-直播场控专家.md | 直播场控专家 |

**评审与会议** —— `YYYYMMDD-{主题}-{类型}.md`，日期取**会议日期**便于按时间排序：

- `转写稿` = 会议录音的原始转写，含时间戳，未经整理
- `总结` = 在转写稿基础上整理的结论，对外可用
- `会议纪要` = 前两者合并成一篇，结论在前、转写稿作附录附于文末

## 归档约定

`archive/` 下全部是已被取代、且全仓库无引用的快照，**运行时不加载任何东西**。确认长期不再需要后可以删除（git 历史里仍可找回）。当前归档：4 个历史 demo 快照。
