# AI数班视觉系统

## 定位

AI数班是面向汽车品牌与门店运营者的数字员工经营控制台。视觉应保持安静、专业、可信，让经营结果、待办和主操作优先于装饰。

## 颜色语义

| 用途 | 颜色 | 规则 |
| --- | --- | --- |
| 画布 | `#F6F7F7` | 页面背景，避免纯白大面积铺满 |
| 内容面 | `#FFFFFF` | 卡片、表格、弹窗和编辑区域 |
| 主操作 | `#111111` | 雇佣、保存、确认等主要动作；黑色是唯一品牌强调色 |
| 主操作悬停 | `#2B2B2B` | 主操作的悬停和按下状态 |
| 信息 | `#3269C8` | 链接、数据、辅助操作 |
| 成功/在线 | `#2F8F62` | 仅表示已完成、在线、运行中 |
| 注意/人工 | `#765F43` | 待处理、待确认、人工决策；大面积使用 `#F7F3EE` 浅底 |
| AI 专属 | `#7359B5` | 仅用于小班和 AI 专属能力 |
| 主文字 | `#171717` | 标题、重要数据和正文 |
| 辅助文字 | `#687076` | 说明、次要信息和时间 |
| 边框 | `#E2E5E5` | 弱边界，避免多层线框 |

## 排版

- 页面标题：28–34px，字重 700，行高 1.2。
- 模块标题：16–20px，字重 700，行高 1.35。
- 正文：13–14px，行高 1.55。
- 辅助信息：12px，行高 1.45；可见文字不得小于 12px。
- 不使用负字距，不用视口宽度缩放正文。

## 空间与形状

- 间距只使用 4 / 8 / 12 / 16 / 24 / 32px。
- 常规卡片圆角 8px；重点容器最多 12px。
- 边框优先于阴影建立层级；阴影保持轻量：`0 8px 24px rgba(17, 17, 17, .07)`。
- 图片使用固定比例或稳定高度，避免异步加载造成布局跳动。

## 组件规则

- 主按钮使用黑色，次按钮使用白底弱边框，危险动作使用红色但不作为品牌色。
- 状态标签只保留一个主要位置。统一使用：在线工作、可雇佣、待上线、已暂停、待授权。
- 卡片内部按身份、结果、说明、操作排列；操作区贴近卡片底部并保持首屏可见。
- 表格和编辑器保留边界，普通内容区使用留白和背景分区，不叠加多层边框。
- 弹窗使用白色内容面、12px 圆角、明确标题和单一主操作。

## 响应式

- 桌面（≥1281px）：人才广场四列。
- 平板（901–1280px）：人才广场三列。
- 紧凑平板（601–900px）：人才广场两列。
- 窄屏（≤600px）：人才广场单列，导航转为抽屉，所有主操作触控区域不小于 44px。
- 任意视口不得出现横向滚动；长文案自然换行，摘要最多两行。

## Do / Don't

### Do

- 用颜色表达状态，用留白表达层级。
- 让结果数字和主操作在首屏可见。
- 使用真实汽车业务素材，但保持图片服务于岗位信息。
- 为图片、表格和流程节点预留稳定尺寸。

### Don't

- 不让紫色、橙色或蓝色承担主品牌操作。
- 不在同一张卡片重复展示多个状态标签。
- 不用渐变光晕、装饰性网格或动画抢占结果区域。
- 不在普通内容中嵌套卡片套卡片。
